    -   **Discovery/Swipe:** A Tinder-like swipe interface to browse profiles. Cards must show user photo, all information, and common interests/games.
    -   **Filtering:** Users must be able to filter discovery by gender, country (from a searchable dropdown list of all countries), and spoken language (French, English, Spanish, Italian, Mandarin, Arabic).
    -   **Matching:** When two users like each other, it's a match.
    -   **Post-Match:**
        -   Nicknames of both users are revealed to each other.
        -   A private chat is enabled between the matched users.
        -   Users should have the option to block or delete a matched member.
-   **Monetization**:
    -   Free tier: 5 free swipes per day.
    -   Premium tier: Unlimited swipes for a subscription of /week (UI only for now, no real payment integration).
-   **Other Features**:
    -   Password Reset: A forgot password functionality.
    -   Shareable Link: A link that can be shared with friends to invite them to create a profile and test the app.
-   **Design & UX**:
    -   A dark theme with a black background.
    -   Accents of blue and pink, applied harmoniously throughout the application.
